# Freely-licensed video clips, for filling the feed up during testing.
#
#   dart run tools/seed_feed.dart --user NAME --password PASS \
#       --source urls --urls-file tools/public_clips.txt --count 60 --yes
#
# Every link here was checked and served a real MP4. That check matters more
# than it sounds: the sample-video hosts everyone used to link to have mostly
# gone away. Google's old gtv-videos-bucket, the one behind half the tutorials
# on the internet, now answers "AccessDenied" to everyone.
#
# LICENCES. The Blender films (Sintel, Big Buck Bunny) are Creative Commons
# Attribution — free to use, including commercially, as long as the film is
# credited. The Mozilla clips are CC0, which asks for nothing at all. That is
# fine for filling a test feed, which is all this file is for. If any of this
# ever ends up in front of real users, the Blender ones need a credit line.
#
# SIZES are in the comments so you can see what you are about to pull down.
# The whole list is roughly 35 MB.
